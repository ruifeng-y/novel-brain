# 墨舟 · NovelBrain 原型

这是第一版可点击的 Web 原型，用仙侠样例《仙途：忘川书》演示从想法到连载、修改与平行版本的完整主流程。

## 打开方式

直接用浏览器打开：

`D:\AI\Codex\novel-brain\prototype\index.html`

不需要安装依赖，也不需要启动开发服务器。

## 页面

- 工作台：多作品、进度、今日任务、最近修改。
- 新建作品：灵感输入、题材包、故事规模、生成故事蓝图。
- 故事圣经：一句话故事、核心卖点、主角、金手指、世界铁律、主线支线、结局、读者承诺。
- 设定中心：世界、势力、人物、地图、修炼体系、物品功法、时间线。
- 大纲工作台：全书、卷、章、场景节拍、章末钩子。
- 写作台：章节编辑器、编辑建议、连续性提醒、伏笔提示、行内批注。
- 批量生产：按章、按卷、自定义、全本，预算、审批方式、任务 DAG。
- 修改与版本：修改请求、影响分析、平行版本、版本线、并排比较。
- 导出弹窗：TXT、Markdown、DOCX、EPUB。

## 可以点的演示

- 左侧导航切换页面。
- 新建作品里点“法医穿仙侠”填入灵感，再点“生成故事蓝图”，会进入故事圣经。
- 设定中心切换“地图”，查看人界、灵界、仙界的分层地图。
- 写作台切换章节，点击正文里的红色“批注”，查看编辑建议、连续性、伏笔三个面板。
- 批量生产切换生成范围、拖动预算滑杆。
- 修改与版本里查看影响分析，选择“从第 18 章拉平行版本”。
- 导出与发布打开导出弹窗。

## 说明

- 这是前端静态原型，没有连接后端、模型、数据库或账号系统。
- 视觉方向是“专业编辑部工作台”，不是聊天机器人。
- 已检查 1440、1180、900、390 四个宽度，无横向溢出和控制台错误。
- 截图在 `screens/` 目录。
