# 墨舟 · NovelBrain 原型

这是第一版可点击的 Web 原型，用仙侠样例《仙途：忘川书》演示从想法到连载、修改与平行版本的完整主流程。

## 打开方式

直接用浏览器打开：

`D:\AI\Codex\novel-brain\prototype\index.html`

不需要安装依赖，也不需要启动开发服务器。

## 页面

- 工作台：多作品、进度、今日任务、最近修改。
- 新建作品：一句话想法、空白作品、题材模板、导入旧稿、作品信息、故事蓝图预览。
- 作品总览：连载状态、卷进度、准备度、待处理提醒、最近章节和快捷入口。
- 故事圣经：九卡导航、完成度、一句话故事、核心卖点、主角、金手指、世界铁律、主线、支线、结局、读者承诺。
- 故事圣经支持进入/退出编辑、AI 一致性检查、AI 补全提案和逐卡编辑。
- 设定中心：左侧分类导航，世界、人物、势力、地图、力量体系、物品功法、金手指、时间线、已确认设定、自定义字段；人物、势力、物品和地图条目共用完整档案页，包含基本信息、核心驱动、认知边界、类型化关系、状态历史、引用和体检；自定义字段支持类型、适用对象、必填、选项、关系引用和启停。
- 大纲工作台：全书、卷、幕、章、场景五层树，以及树状、章节看板、张力曲线、账本四个视图；含黄金三章开篇策略编辑。
- 伏笔账本：新增、编辑、筛选、标记回收、放弃，记录埋设章、计划回收章、重要程度、关联人物势力、读者承诺，并检查过期、未埋设回收、重复线索和回收力度。
- 写作台：章节编辑器、编辑建议、连续性、伏笔、事实确认、人物状态、质量报告、专注模式、行内批注。
- 批量生产：按章、按卷、自定义、全本，审批方式、token/费用预估、任务 DAG、审核队列和任务报告。
- 修改与版本：修改请求、影响分析、平行版本、版本图、回滚、审计记录、并排比较和选择性摘取。
- 导出与发布：独立页面、四种格式、当前章/选中章节/自定义/整卷/全本/平行版本/历史版本范围、目录预览、版本清单、导出历史、发布检查。
- 账号与模型：模型配置、连接测试、账号安全、数据导出与隐私入口。
- 作品设置：书名、笔名、题材、平台、读者、字数、节奏、简介、标签、封面，以及复制、归档、删除。
- 登录与注册：登录、注册、找回密码、恢复账号，并带验证码错误、限流、邮件发送和链接失效状态。
- 全局搜索与通知：跨作品、设定、人物、大纲和已确认设定搜索；站内通知抽屉。
- 全局搜索按作品/人物、势力与地图、章节正文、已确认设定分组，并高亮关键词。
- 界面状态：正常、空、加载、错误、锁定、只读、冲突七种状态演示；顶栏“演示模式”可在任意页面切换。
- 法律与帮助：用户协议、隐私政策、AI 内容说明、快捷键、术语和常见问题。

## 可以点的演示

- 左侧导航切换页面。
- 新建作品里切换“一句话想法 / 空白作品 / 题材模板 / 导入旧稿”。
- 导入旧稿可以改章节标题、拆分章节、合并下一章。
- 新建作品里点“法医穿仙侠”填入灵感，再点“生成故事蓝图”，会进入故事圣经。
- 点“创建作品并进入总览”查看作品级首页。
- 设定中心切换“地图”，查看人界、灵界、仙界的分层地图。
- 世界规则页的核心势力列表、地图 SVG 上的门派标记、地图详情卡都可以直接打开对应档案。
- 世界规则页的人界/灵界/仙界层级卡、力量体系的境界节点、时间线事件、金手指使用记录都可以点开对应档案。
- 设定中心切到“人物档案”，点击沈砚、顾青或玄微真人的卡片，进入完整档案页；左侧目录可在基本信息、关系、状态历史、引用和体检之间跳转，点击关系里的人物可直接切换档案。
- 设定中心切到“势力”或“物品功法”，点击太玄门、血河宗、无相楼、忘川书、听潮剑、半枚青玉，进入对应的完整档案页。
- 设定中心切到“地图”，点击右侧层级节点打开人界、东境、忘川渡、太玄门山门的地点档案；金手指页的“打开完整档案”也会进入忘川书详情。
- 世界规则、力量体系、时间线和已确认设定页都提供“打开档案”入口，进入同一套整页详情。
- 仙侠/历史/都市的题材演示会同步更新新建作品预览、设定中心地图势力说明和写作台规则提示。
- 力量体系的境界节点、时间线事件都可以点开档案；已确认设定支持按类型筛选，事实行可以直接跳到关联人物、物品或事件档案。
- “搜索设定”打开全局搜索；世界规则的“查看修复建议”和人物的字段预览也会跳到对应档案或体检分区。
- 设定中心切换“自定义字段”，筛选、新增、编辑、停用字段，查看人物档案字段预览。
- 写作台切换章节，点击正文里的红色“批注”，查看编辑建议、连续性、伏笔三个面板。
- 写作台可以新建章节草稿、生成整章、续写、检查连续性、保存版本、应用钩子建议，并确认或驳回事实提案。
- 写作台右侧切换事实、人物和质量，查看命中事实确认与六维质量报告。
- 批量生产切换任务列表、审核队列和任务报告。
- 批量生产可以暂停/恢复任务、批量批准低风险章节、逐章批准或驳回，并实时更新审核队列数量。
- 伏笔账本新增一条伏笔、筛选已回收、标记回收，右侧看四项风险检查。
- 修改与版本里查看影响分析，选择“从第 18 章拉平行版本”。
- 修改与版本底部查看版本图、回滚和审计记录。
- 导出与发布查看目录预览、导出历史和发布检查。
- 导出与发布可以创建导出任务、复制当前章、生成发布文案、重新运行发布检查；作品设置可以保存并进入作品操作确认流程。
- 导出页支持读者预览定位、展开完整目录和查看发布检查详情；帮助页快捷键入口会定位到说明卡。
- 登录与注册页支持验证码倒计时、重置邮件提示和恢复申请反馈；界面状态页的错误、锁定和只读状态都有可操作出口。
- 顶部搜索框打开全局搜索；铃铛打开通知抽屉。
- 账号设置里进入“界面状态”或“退出登录”，查看账号入口。
- 点右上角头像打开用户菜单，选“退出登录”进入登录页；侧栏用户卡也有退出按钮。
- 作品总览进入“作品设置”，查看作品级字段和危险操作。
- 侧栏底部进入“帮助”；账号设置底部进入法律页。

## 说明

- 这是前端静态原型，没有连接后端、模型、数据库或账号系统。
- 视觉方向是“专业编辑部工作台”，不是聊天机器人。
- 页面内可见按钮均已接入导航、弹窗、状态变化或模拟下载；不再有 `data-action="toast"` 占位。
- 下载、导出、复制、连接测试为前端模拟行为，不会真正调用后端或平台接口。
- 已检查 1440、1180、900、390 四个宽度，无横向溢出和控制台错误。
- 全站可见文字最小字号 12px，关键交互按钮最小点击高度 24px。
- 已用内置浏览器逐页签收 18 个页面，并复验搜索、通知、账号菜单、设定弹窗、新建向导、章节切换和大纲看板。
- 最新整页签收截图在 `../test-results/visual-signoff/full/`；`screens/` 保留过程截图。
