## P2 残余风险

### 历史版本导出

- 当前同步生成 ZIP；超大历史可能占用请求时间和内存，后续应后台化。
- 地图图片二进制不打包在历史版本 ZIP 中。
- manifest 和版本清单会随版本/章节数增长；超大作品需要分页或流式生成。

### 运维 CLI

- 密码重置通过邮件链接完成；还没有独立 CLI 重置密码。
- 账号禁用和开关注册目前需要安全流程/数据库操作，没有一键运维命令。

### 浏览器与监控

- Edge、Safari 最近两个大版本未执行。
- Prometheus/Grafana/OpenTelemetry/Sentry/Langfuse 监控链未随仓库部署验证。

### 规模与吞吐

- 30 章 2-4 小时和 1,000 章 3-5 天是模型化结果，不是真实模型墙钟。
- 多用户、多作品同时长时间运行只验证了 4 个任务的小样本。
- 1,000 章夹具使用本地 Postgres 和 `ANALYZE` 后的稳定统计信息。

### 依赖

- `minio@8.0.7` 依赖的 `stream-json@1.9.1` 仍有 3 个 moderate 告警，位于未调用
  的桶通知解析路径；启用桶通知前必须清除。

## 结论

所有工程 P1 已关闭，无已知代码 P0/P1。B-05、B-06、B-08 和 B-07 live cloud 证据
是严格外部门槛；P2 项目可在公开前排期。当前版本可作为局域网/内部发布候选，
不得标记为 V1 正式公开发布。
