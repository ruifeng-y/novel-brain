# NovelBrain V1 已知限制

> 版本：V1.0.0-rc.1（验收候选）  
> 日期：2026-11-02  
> 代码基线：`c424aed`

本文把已实测、未验证和未交付的范围分开。不要把“本地 fake provider 通过”理解为

## 已实测通过

- 干净 Compose 项目启动 8/8 服务，37 条迁移和 seed 成功。
- 43 个 Vitest 文件、208/208 测试。
- 35/35 Playwright（Chromium 桌面 + 390px 移动视口）。
- lint、typecheck、生产构建。
- 3,000,000 字 / 1,000 章夹具的打开、列表、单章、自动保存、设定 CRUD、搜索、
  首 token、SSE 和 4 任务并发。
- 代码级安全专项 18/18：Argon2id、session hash、RLS、对象前缀、Key 信封加密、
  日志脱敏、导出限流和备份守卫。
- Postgres + 对象存储备份与恢复演练：3 秒恢复，3/3 对象逐字节校验。
- 依赖审计 high 门槛：0 high、0 critical、3 moderate。

## 未验证

### 真实 DeepSeek

- 文本质量、中文长文稳定性、结构相似度和 AI 腔。
- 真实首 token、SSE 延迟、排队、限流、余额不足、重试和失败恢复。
- 真实 token 费用和长上下文表现。
- 真实供应商返回不符合事实抽取 JSON Schema 时的降级路径。

所有自动验收使用确定性 fake provider；fake 文本只用于验证状态机、上下文、
SSE、持久化和检查器，不代表文学质量。

### 人工质量门禁

- 10 名目标读者盲评和 70% 追读率。
- 章末钩子 4/5 分。
- 每 5 万字不超过 1 个连续性硬伤。
- 大纲贴合度 90%。
- 必须回收伏笔回收率 90%。
- 人物声纹、重复度、AI 腔人工量表和文本质量。

### 浏览器与部署

- Edge、Safari 最近两个大版本。
- Linux 生产主机、云数据库、云对象存储、跨区域网络。
- 生产 SMTP、TLS/HSTS、证书轮换。
- 数据库/备份/对象存储静态加密。
- 30 天日志保留、访问控制和审计导出。
- Prometheus/Grafana/OpenTelemetry/Sentry/Langfuse 监控链。
- 异地/离线备份和真实灾备切换。

### 规模与吞吐

- 30 章 2-4 小时和 1,000 章 3-5 天是模型化结果，不是真实模型墙钟。
- 多用户、多作品同时长时间运行只验证了 4 个任务的小样本。
- 1,000 章夹具使用本地 Postgres 和 `ANALYZE` 后的稳定统计信息；生产 autovacuum
  行为和长期膨胀未验证。

## 安全与合规残余

- 仅有 3 个 moderate 依赖告警，来自 `minio@8.0.7` 的
  `stream-json@1.9.1` 桶通知解析路径；产品当前不调用该路径。启用桶通知前必须
  清除。
- Caddyfile 仍然是本地 HTTP 配置；公开访问需要 TLS、HSTS 和证书管理。
- 对象下载当前经 API 校验作者后代理读取，未使用短时签名链接；如果改成直连对象
  存储，必须增加签名和前缀限制。
- 本地 Compose 使用开发密钥和默认数据库密码；生产必须替换并删除
  `ALLOW_DEFAULT_DB_PASSWORD`。
- L-01 到 L-12 法务/运营事项仍待负责人确认，包括运营主体、模型数据处理条款、
  备案、审核边界、AI 标识、私有部署责任、注销实现、协议、TLS/加密/日志、
  删除例外、版权投诉和演示授权。

## 结论

这些限制中的 B-01 到 B-08 是 V1 公开发布阻断项。它们关闭前，NovelBrain 只能
作为局域网/内部发布候选使用。
