# NovelBrain V1 发布说明（局域网/内部 RC）

> 版本：V1.0.0-rc.2（内部发布候选）
> 日期：2026-11-03
> 代码基线：`808a16b`
> 分支：`codex/ticket-33-v1-acceptance`
> 结论：**局域网/内部 RC GO；正式公开发布 NO-GO**

## 摘要

本候选版本在 `c424aed` 验收候选基础上关闭了 B-01、B-02/B-03、B-04 和 B-07 的
工程发布门槛：

- 账户生命周期与多笔名。
- 账号级审计与完整数据导出。
- 作品导入、归档、软删除、恢复、复制、完本只读和书架指标。
- 生产 TLS/HSTS、签名下载、脱敏日志、生产 SMTP、异地备份配置和部署检查。

自动化功能、数据库集成、构建、浏览器、性能和恢复演练通过。它现在可以作为
局域网/内部 beta 发布候选使用。

它仍不是完整 V1：工作级资料/设置和独立大纲/历史版本导出（B-12/B-13）未交付；
人工质量盲评（B-05）、真实 DeepSeek（B-06）、法务/运营确认（B-08）和真实云部署
证据（B-07 外部部分）仍是公开发布门槛。

## 本候选包含

### 账户与安全

- 邮箱验证码注册、登录、找回密码、重置密码、修改密码、修改邮箱。
- 显示资料、头像链接、简介、多笔名和作品署名。
- 注销申请、30 天恢复、永久删除、删除回执和后台清理任务。
- 登录、退出、Key 变更、导出、删除、生成和事实决策的账号级审计。
- 完整账号 ZIP 导出，包含作品、设定、地图、人物、事实、修改记录和审计。
- 短时签名下载、7 天导出保留和作者隔离。

### 创作闭环

- 仙侠、历史、都市三题材作品和题材包。
- 故事圣经、设定中心、人物档案/状态、地图/势力、力量体系、物品功法、时间线。
- 五层大纲、剧情线、伏笔、人物弧账本和准备度。
- 三栏写作台、流式生成、续写/重写/扩写/缩写/改视角/钩子/标题/摘要。
- 事实抽取与确认、连续性检查、六项质量报告、批注和版本历史。

### 批量、修改与版本

- 按章、按卷、自定义区间、全本批量任务和审核队列。
- 暂停、恢复、取消、失败重试、任务报告和并发门限。
- 修改请求、影响分析、六步一致性检查、平行版本、选择性摘取和版本图回滚。

### 导出、发布与作品生命周期

- TXT、Markdown、DOCX、EPUB；通用网文、起点、番茄预设。
- 预览、后台导出、7 天下载历史和短时下载链接。
- 发布建议、读者预览、六项发布检查和报告复制/下载。
- TXT/Markdown/DOCX 旧稿导入并按章节切分。
- 作品归档、回收站、30 天恢复、复制作品、完本只读和 30 天永久清理。
- 书架搜索、状态/题材/字数筛选、质量分、未回收伏笔和进度/字数。

### 生产部署

- `docker-compose.production.yml`、`infra/caddy/Caddyfile.production` 和生产 env 示例。
- TLS/HSTS、HTTP→HTTPS、Secure Cookie 和生产启动检查。
- 生产 SMTP TLS/证书配置、JSON 日志和 30 天轮转配置。
- `pnpm deploy:check`、`pnpm deploy:verify`、`pnpm deploy:smoke`。
- offsite 备份复制、SHA-256 清单和恢复核对。

## 升级与迁移

- 本候选在空 Postgres 16 schema 执行 `0000` 到 `0049` 共 50 条迁移。
- 新增迁移覆盖账户生命周期、审计/导出、作品归档和永久清理；生产使用前必须
  备份并核对迁移计数。
- 账号和作品永久清理任务需要 `DATABASE_ADMIN_URL`，生产先 dry-run。
- 回滚以备份恢复为主；项目没有 down migration。
- 完整步骤见 `docs/release/v1-migration-rollback-runbook.md`。
