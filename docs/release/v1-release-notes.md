# NovelBrain V1 发布说明（发布候选）

> 版本：V1.0.0-rc.1（验收候选）  
> 日期：2026-11-02  
> 代码基线：`c424aed`  
> 验收分支：`codex/ticket-33-v1-acceptance`  
> 发布结论：**未批准公开发布**

## 摘要

本候选版本完成 NovelBrain V1 的主要创作与发布准备能力：三题材作品、故事圣经、
结构化设定、五层大纲、剧情/伏笔/人物弧账本、写作台、事实确认、连续性/质量检查、
批量生产、审核队列、修改影响分析、平行版本、版本图/回滚、TXT/Markdown/DOCX/EPUB
导出、发布检查、读者预览、数据隔离、Key 信封加密、备份和恢复演练。

本轮 V1 总验收没有发现测试路径中的 P0；自动化功能、性能、代码级安全、构建和恢复
演练通过。但 V1 公开发布门槛没有通过：质量盲评、真实 DeepSeek、作品生命周期、
TLS/静态加密/日志保留和法务事项仍未闭环。

**结论：可作局域网/内部发布候选验收，不得标记为 V1 正式公开发布。**

## 本候选包含

### 创作闭环

- 邮箱验证码注册、密码登录、退出当前设备、退出所有设备。
- 仙侠、历史、都市三题材作品和题材包。
- 故事圣经、设定中心、人物档案/状态、地图/势力、力量体系、物品功法、时间线。
- 全书/卷/幕/章/场景五层大纲、剧情线、伏笔、人物弧账本和准备度。
- 三栏写作台、整章/续写/重写/扩写/缩写/改视角/钩子/标题/摘要。
- 事实抽取、作者确认后进入正史、上下文续接。
- 连续性检查、六项质量报告、批注、忽略原因和版本历史。

### 批量、修改与版本

- 按章、按卷、自定义区间、全本批量任务。
- 暂停、恢复、取消、失败步骤重试、审核队列和任务报告。
- 修改请求、影响分析、安全/可修复/结构性冲突、六步一致性检查。
- 并行草稿、正史串行提交、并发门限和交互式优先队列。
- 平行版本、copy-on-write、并排比较、选择性摘取。
- 版本图、不可删除历史、撤销、回滚和审计 CSV。

### 导出、发布与安全

- TXT、Markdown、DOCX、EPUB；通用网文、起点、番茄预设。
- 当前章、选中章节、区间、卷、全本、指定分支；预览、后台导出、7 天下载历史。
- 书名/简介/标签/章节名建议、读者预览、六项发布检查、复制/下载报告。
- RLS 租户隔离、对象存储前缀、Argon2id、opaque session hash、httpOnly Cookie。
- 模型 Key 信封加密、掩码、错误脱敏、接口限流。
- Postgres + 对象存储每日备份、30 天保留、恢复演练 CLI。
- 隐私政策、用户协议、AI 内容标识、内容审核和安全检查清单。

### 本轮修复

- **作品书架字数/进度**：`GET /api/v1/works` 和 `GET /api/v1/works/:workId` 现在从
  主分支章节聚合真实字数和完成进度，不再固定返回 0。新增 API 回归测试。

## 升级与迁移

- 本候选在空 Postgres 16 schema 执行 `0000` 到 `0047` 共 48 条 Drizzle 迁移。
- 账号审计索引和账号导出任务迁移位于 `0046`–`0047`，位于账号生命周期迁移之后。
- 升级前先备份 Postgres 和对象存储，再执行迁移。
- 回滚以备份恢复为主；项目没有 down migration。
- 完整步骤见 `docs/release/v1-migration-rollback-runbook.md`。

完整阻断项、级别和关闭条件见 `docs/acceptance/m3/acceptance.md`。
