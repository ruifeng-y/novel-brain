# M2 扩大 beta 验收

> M2 是仙侠、历史、都市三题材的内部扩大 beta，不是 V1 公开发布版本。

本目录记录 GitHub issue #27「M2-07 多题材与修改版本验收」及 M2-01 到 M2-06 的
集成验收证据。

- `acceptance.md`：验收范围、命令结果、缺陷、已知限制和 P0/P1 结论。
- `demo.md`：内部演示步骤和自动验收方式。
- `metrics.json`：确定性 fake provider 环境下的性能 smoke 样本。
- `screenshots/`：三题材、批量审核、修改影响、平行版本和回滚证据。

M2 验收不调用真实 DeepSeek，也不代表已达到公开出版、合规、灾备或真实模型质量门槛。
