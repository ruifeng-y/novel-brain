## 发现并修复的问题

真实验收发现：正文生成成功后，事实抽取调用没有传递模型名、API Key 和 Base URL，导致任务在 `extract_facts` 阶段报 `MODEL_CONFIG_REQUIRED`。

修复：PR #41，事实抽取接收并传递完整模型配置，补充回归测试。修复后三章连续生成通过。
