# M0 Acceptance Plan

> 关联：M0 Spec #66、ADR 0024、`docs/technical/m0-protocol-freeze.md`
> 目标：证明 M0 是可用闭环，而不是静态页面或假接口。

## 1. 测试层次

| 层 | 范围 | 工具 |
| --- | --- | --- |
| 单元 | 状态机、门禁、上下文选择、错误映射 | Vitest |
| 契约 | Zod/OpenAPI、请求响应、错误码 | Vitest |
| 集成 | API + Postgres + Redis，Worker + fake provider | Vitest + Testcontainers 或本地 Compose |
| E2E | 作者主流程、失败恢复、UI 门禁 | Playwright |
| 视觉 | 生产页面四档截图、作者语言扫描 | Playwright Chromium |
| 真实模型 smoke | DeepSeek 连接、流式、结构化输出、成本记录 | 独立手动/夜间任务 |
| 安全 | RLS、跨用户访问、Key 掩码、日志脱敏、SSRF | Vitest + API E2E |

## 2. 主验收旅程

### J1 注册登录

1. 请求邮箱验证码。
2. 注册。
3. 登录。
4. 调用 `/auth/me`。
5. 登出。
6. 旧会话失效。

### J2 配置 DeepSeek

1. 新增 DeepSeek 官方配置。
2. Key 只返回掩码。
3. 连接测试成功。
4. 错误 Key 返回 `MODEL_KEY_INVALID` 或 `MODEL_CONNECTION_FAILED`。
5. Key 不进入日志和导出。

### J3 想法开书到单章闭环

1. 用一句话想法创建作品。
2. 生成九卡故事圣经提案。
3. 编辑并锁定故事圣经。
4. 生成最小章纲。
5. 创建单章生成 Job。
6. fake provider 返回确定性结果。
7. 页面显示草稿、来源、上下文和成本。
8. 抽取事实提案。
9. 确认部分事实、驳回一条事实。
10. 批准章节。
11. 提交本章事实。
12. 已确认设定视图出现新事实。

### J4 设定导入门禁

1. 从部分设定开书。
2. 系统识别人物、势力、地图、力量体系和金手指候选。
3. 报告显示 1 条冲突。
4. 冲突未裁决时不能创建作品。
5. 裁决后可确认并创建。

### J5 旧稿文本导入

1. 上传小型 TXT/Markdown fixture。
2. 系统切分章节。
3. 作者可改标题、拆分、合并。
4. 默认模式不自动写入已确认设定。

### J6 失败与恢复

1. 模型连接超时。
2. Job 停在失败步骤并保留草稿/检查点。
3. 修复模型配置后从检查点重试。
4. 已完成步骤不重写。

## 3. UI 验收

- 使用固定 fixture，保证每次渲染数据一致。
- 在 Chromium、固定字体环境下生成 1440/1180/900/390 截图。
- 第一版页面经作者对照原型确认后，截图成为生产 golden baseline。
- 后续 CI 用视觉 diff 拦截漂移；允许差异阈值在首次签收时固定。
- 关键动作和门禁使用 Playwright role/name 断言，不依赖 CSS 类名。
- 作者语言扫描禁止内部术语。

## 4. 必测反例

- 事实确认后不能直接出现在已确认设定。
- 章节未批准时不能提交本章事实。
- 仍有待确认事实时不能提交。
- 导入冲突未裁决时不能创建作品。
- 旧稿文本导入默认不写已确认设定。
- Key 明文不能出现在响应或日志。
- 跨用户访问作品、章节、事实、模型配置必须返回禁止错误。
- 预算耗尽必须停止并保留检查点。
- 模型连接失败不能生成假成功页面。

## 5. CI 门禁

合并前必须通过：

- lint、format check、typecheck。
- 单元、契约、集成测试。
- M0 API E2E。
- M0 Playwright 主旅程。
- 四档响应式与视觉基线。
- 作者语言扫描。
- RLS/跨用户安全测试。
- 迁移从空库执行成功。

真实 DeepSeek smoke 不阻塞每个 PR，但 M0 demo-ready 前必须通过并保存证据。

## 6. M0 Done

M0 只有同时满足以下条件才算完成：

- J1–J6 全部通过。
- 五个开书入口可用。
- 故事圣经可生成、编辑、锁定。
- 单章生成、上下文来源、版本和生成轨迹可查看。
- 事实确认、章节批准、故事事实提交三段门禁不可绕过。
- 已确认设定视图能看到提交结果。
- M0 UI 页面与原型一致并通过视觉基线。
- 跨用户隔离和 Key 安全测试通过。
- 确定性 fake provider 测试稳定。
- 一次真实 DeepSeek smoke 通过。
