# NovelBrain V1 原型范围基线

> 状态：已确认  
> 日期：2026-11-03  
> 适用范围：`prototype/` 可点击设计原型  
> 约束：本文只定义原型，不定义生产实现；原型定稿前不改生产 UI。

## 1. 原型目标

原型是 V1 的完整可点击设计基线，不是视觉方向稿，也不是生产代码。

- 覆盖 V1 全部页面、主流程、关键状态和桌面/移动端。
- 所有主按钮必须在原型内产生可见结果。
- 原型未覆盖的页面视为 UI 未完成，不能进入生产实现。
- 原型使用本地假数据和会话内状态；刷新后可以重置。
- 生产 UI 必须按原型重做；后端、数据库、Worker 和领域能力保留。

## 2. 视觉方向

保留“专业编辑部工作台”的视觉语言：

- 产品名：墨舟；英文副标：NovelBrain。
- 深色左侧栏、纸色背景、朱砂/玉色/金色强调。
- 标题使用衬线字体，正文保持高可读性。
- 信息密度接近编辑部工作台，不做聊天机器人界面。
- 卡片、表格、时间线、版本图和地图标记共同组成视觉语言。

## 3. 导航与信息架构

### 3.1 账号级

未进入作品时，左侧栏只保留：

- 工作台
- 设置

工作台就是作品书架，不再单独设置“作品”页面。

### 3.2 作品级

进入作品后，左侧栏切换为：

- 作品总览
- 故事圣经
- 设定中心
- 大纲工作台
- 伏笔账本
- 写作台
- 批量生产
- 修改与版本
- 导出与发布
- 返回工作台

设置仍在账号级，包括模型设置、账号设置、隐私与数据、法律页。

### 3.3 顶部栏

顶部固定：

- 面包屑
- 全局搜索
- 通知中心
- 用户菜单

侧栏可折叠；移动端侧栏变为抽屉。

## 4. 页面清单

### 4.1 账号

- 登录
- 注册
- 找回密码
- 恢复账号

账号页必须覆盖验证码倒计时、验证码错误、登录限流、邮件已发送、链接失效、密码强度不足和恢复账号确认。

### 4.2 工作台

工作台是账号级作品书架，包含：

- 继续写作主卡
- 作品卡片：封面、状态、进度、字数、最后编辑、质量分、未回收伏笔
- 今日任务：待确认事实、连续性问题、待选钩子
- 最近修改
- 搜索、状态筛选、题材筛选、字数筛选、最近编辑筛选、排序
- 归档、回收站、恢复、永久删除
- 新建作品入口

### 4.3 新建作品向导

支持四种入口：

- 一句话想法
- 空白作品
- 题材模板
- 导入旧稿

向导步骤：

1. 灵感
2. 题材与子类型
3. 规模、目标平台、目标读者、章节字数、更新节奏
4. 读者承诺、禁忌、风格样本、简介、标签、封面
5. 故事蓝图预览
6. 创建作品

规则：

- 书名、笔名、题材、规模、目标平台为必填。
- 其余字段可以跳过。
- 故事蓝图预览展示九卡摘要，可返回修改。
- 正式九卡编辑在创建后的故事圣经中完成。
- 导入旧稿支持 TXT、Markdown、DOCX，先预览章节切分，可调整标题、合并或拆分。
- 导入保留原文，V1 不自动抽取人物和设定。
- 创建后进入作品总览，并显示准备度清单。

### 4.4 作品总览

作品总览是作品级首页，包含：

- 封面、书名、笔名、题材、规模、平台、状态
- 创作进度、累计字数、最近编辑、质量分、未回收伏笔
- 故事圣经、大纲、正文准备度
- 各工作区快捷入口
- 最近章节和最近修改
- 待处理事实、连续性、质量、任务提醒
- 作品设置入口
- 更多操作：归档、恢复、移入回收站、恢复、永久删除、完本、恢复连载、复制作品

复制作品对话框允许选择复制设定、大纲、正文和版本。永久删除必须二次确认。

作品设置包含笔名、题材包、目标平台、目标读者、规模、章节字数、更新节奏、风格样本、禁忌、简介、标签和封面。模型配置仍在账号级。

### 4.5 故事圣经

三栏布局：

- 左：九张卡片导航
- 中：当前卡片的摘要和详情
- 右：完成度、健康提醒、修改记录

九张卡片：

- 一句话故事
- 核心卖点
- 主角
- 金手指
- 世界铁律
- 主线
- 支线
- 结局方向
- 读者承诺

功能：

- AI 补全和扩写先出提案，作者接受或放弃。
- 保存、锁定、锁定后修改填原因。
- 历史版本和修改记录。
- 未完成卡片明确标出，并阻止正式生成。
- 可跳转到相关设定和大纲。

### 4.6 设定中心

左侧二级导航：

- 世界规则
- 人物档案
- 势力
- 地图
- 力量体系
- 物品功法
- 金手指
- 时间线
- 已确认设定
- 自定义字段

所有设定条目统一具备：

- 名称、类型、别名、标签
- 摘要、详情
- 自定义字段
- 关系
- 状态历史
- 引用
- 体检结果

人物档案：

- 基础档案
- 欲望、恐惧、秘密
- 声纹样本
- 人物弧光
- 当前状态
- 知识真相与角色认知
- 关系、持有物、所在地

势力：

- 目标、资源、控制区
- 势力关系
- 兴衰时间线

地图：

- 分层地图树
- 地点节点和连接
- 旅行时间
- 势力控制区
- 地图图片标记
- 人物当前位置
- 地点冲突提醒

力量、物品、金手指和时间线按需求字段完整呈现，并随题材包显示不同字段。

已确认设定：

- 事实卡列表
- 来源章节
- 确认时间
- 有效期
- 类型和关键词筛选
- 跳转来源

通用功能：

- 列表搜索、筛选、排序
- 新增、编辑、删除、别名、标签
- 关系图
- 状态历史
- 设定体检
- AI 生成设定提案
- 引用和反向引用
- 自定义字段：文本、长文本、数字、日期、单选、多选、布尔、关系引用；记录适用对象、必填、选项、关系目标和启停状态；新增只追加，不破坏已有字段和数据

### 4.7 大纲工作台

三栏布局：

- 左：五层树
- 中：节点编辑
- 右：准备度、账本和体检

五层：

- 全书
- 卷
- 幕
- 章
- 场景（高级模式，可折叠）

每层按需求展示目标、冲突、转折、高潮、钩子、人物、地点、时间、伏笔等字段。

视图：

- 树状大纲
- 章节看板
- 张力曲线
- 剧情线账本
- 伏笔账本
- 人物弧光账本

操作：

- 新增、排序、锁定、局部重生成、删除
- 生成准备度检查
- 跳转写作台
- 关联伏笔、剧情线和人物弧
- 章级节拍必做

黄金三章开篇策略：

- 第一钩子
- 主角出场
- 世界规则展示
- 第一个爽点
- 三章章末钩子
- 可编辑、保存和独立验收

伏笔的完整管理放在独立“伏笔账本”页：记录线索内容、埋设章、计划回收章、状态、重要程度、关联人物和势力、读者承诺；支持新增、编辑、筛选、标记已回收、放弃，并检查过期未回收、没有埋设就回收、重复线索和回收力度不够。

### 4.8 写作台

三栏加专注模式：

- 左：章节/卷导航、状态、搜索
- 中：标题、正文编辑器、工具栏、字数、自动保存
- 右：编辑建议、连续性、伏笔、人物状态、本章设定
- 顶：生成、续写、重写、检查一致性
- 底：字数、阅读时长、保存状态、模型、token

生成能力：

- 整章生成
- 光标续写
- 选中段落重写
- 扩写、缩写
- 改视角
- 生成章末钩子
- 生成标题和摘要

写作辅助：

- 批注
- 事实提案确认/修改/驳回
- 连续性问题定位、建议和带原因忽略
- 版本保存、比较、恢复
- 质量报告抽屉，包含六维评分、问题清单和建议

规则：

- 正文不能直接改设定。
- 修改设定必须走修改请求。
- 未保存离开时拦截。

### 4.9 批量生产与任务中心

范围：

- 按章
- 按卷
- 自定义区间
- 全本

审批方式：

- 逐章审批
- 逐卷审批（默认）
- 自动通过

规则：

- 自动通过只允许在锁定大纲、标准质量、无高风险时使用。
- 卷末必须人工确认。
- 关键人物死亡、金手指升级、修改已确认设定永远需要确认。
- 显示 token 和费用预估，但不设预算上限。

任务中心：

- 任务列表：排队、运行、暂停、等待审核、完成、失败、取消
- 任务详情：流水线 DAG、当前章节、完成数、错误、控制按钮
- 暂停、恢复、取消、失败重试
- 审核队列：批准并锁定、送写作台修改、驳回重生成、送平行版本、忽略问题并记录原因
- 低风险章节可批量批准，高风险必须逐章看
- 任务报告：完成/失败章节、token、费用、连续性问题、质量摘要、未回收伏笔、下一步建议
- 任务历史
- 站内通知

### 4.10 修改与版本

修改中心：

- 修改请求：标题、原因、目标、旧值、新值、差异、来源、风险、状态
- 影响分析：安全、可修复、结构性冲突
- 受影响章节、设定、伏笔和人物认知
- 六项一致性检查
- 三区规则：已写区、进行区、未写区
- 小修原地留版本，中修走影响报告，大修拉平行版本或明确修订

平行版本：

- 从任意版本点拉分支
- 整本或从某一章开始
- 名称、原因、父版本、分叉点、状态
- 类型：重写、What-if、另一个结局、实验
- 并排比较设定、大纲和正文
- 冲突高亮
- V1 不做自动合并，只做选择性摘取
- 分支归档和删除

版本与回滚：

- 版本图
- 章节、卷、已确认设定快照
- 单次修改撤销
- 分支回滚
- 回滚也产生新版本
- 审计记录

### 4.11 导出与发布

导出独立页面，写作台保留快速导出入口。

格式：

- TXT
- Markdown
- DOCX
- EPUB

范围：

- 当前章
- 选中章节
- 自定义区间
- 整卷
- 全本
- 指定平行版本
- 历史版本

选项：

- 附带故事圣经
- 设定附录
- 大纲
- 伏笔账本
- 修改记录
- 版本清单
- 平台预设：通用网文、起点、番茄
- 章节标题格式、卷标题、段落空行、首行缩进、编码
- 目录和正文预览
- 后台任务和进度
- 导出历史
- 7 天内重新下载
- 单章复制到剪贴板

发布页只做：

- 书名备选
- 简介建议
- 标签建议
- 章节名建议
- 读者预览
- 发布检查清单
- AI 生成内容标识
- 版权和原创性提醒

不绑平台账号，不自动上传。

### 4.12 模型设置

包含：

- 配置列表
- 新增、编辑、删除
- 供应商、Base URL、模型名
- 用途：规划、正文、检查
- 默认配置
- Key 掩码
- 连接测试
- 错误提示和重试

### 4.13 账号、隐私与法律

账号设置：

- 资料
- 笔名
- 密码
- 邮箱
- 会话
- 退出所有设备
- 数据导出
- 删除账号
- 恢复账号

隐私与数据：

- 数据范围
- 导出
- 删除
- AI 内容标识

法律页：

- 用户协议
- 隐私政策
- AI 生成内容说明

不出现管理员后台、团队、成员和配额。

## 5. 全局状态

所有页面统一覆盖：

- 正常
- 空状态
- 加载骨架
- 错误与重试
- 锁定
- 只读
- 冲突

交互规则：

- 破坏性操作、锁定修改、回滚、拉分支用确认弹窗。
- 快速查看用右侧抽屉。
- 完整编辑用独立页面。
- 未保存离开时拦截。
- 操作结果用 toast。
- 全局搜索用命令面板。
- 通知进入站内通知中心。

## 6. AI 提案规则

所有 AI 生成先出提案或差异：

- 故事蓝图
- 故事圣经补全
- 设定生成
- 大纲节点
- 标题
- 钩子
- 摘要
- 改写、扩写、缩写、改视角

作者接受后才落盘；不得静默覆盖；提案可重新生成或放弃。

## 7. 搜索、通知与帮助

全局搜索覆盖：

- 作品
- 设定
- 人物
- 势力
- 地图
- 大纲
- 章节正文
- 已确认设定

结果分组、关键词高亮、可跳转。

通知覆盖：

- 任务完成/失败
- 待审核
- 连续性/质量告警
- 锁定变更

帮助入口放在侧栏底部，包含快捷键、术语表和常见问题。

## 8. 响应式规则

必须检查：

- 1440
- 1180
- 900
- 390

移动端：

- 侧栏变抽屉
- 表格变卡片
- 写作台右侧面板变标签页
- 设定中心列表和详情堆叠
- 批量任务改为卡片
- 版本图和关系图支持缩放或横向滚动

所有宽度不得出现横向溢出。

## 9. 样例数据

主样例：

- 仙侠《仙途：忘川书》
- 多卷、多章、人物、势力、地图、力量体系、物品、伏笔、已确认设定、连续性问题、修改请求和平行版本

差异样例：

- 历史《北境争鼎》
- 都市《南城资本》

历史与都市至少覆盖新建作品、设定中心、地图势力、写作台规则提示的差异。

原型操作在当前会话内改变 UI，刷新后重置。提供演示模式开关，便于逐页展示。

## 10. 原型完成标准

- 页面清单无缺项，全部可从导航到达。
- 每个主按钮有可见结果。
- 无死链接、占位文案和“建设中”。
- 七类全局状态可演示。
- 三题材差异可见。
- 四档宽度无横向溢出。
- 全部使用作者语言，不出现“正史、Canon、Context Pack、Agent”等内部词。
- 作者逐页签收后，才能进入 UI spec 和生产实现拆票。

## 11. 明确不做

- 团队、成员、邀请、角色矩阵
- 管理员后台
- 配额、充值、支付
- 本地模型
- 自动发布和平台账号绑定
- 自动分支合并
- 自由绘制地图
- PDF 导出
- AI 封面
- 读者社区和公开作品
- 定时日更和邮件通知

## 12. 生产实现边界

原型定稿后：

- 保留现有 NestJS API、Worker、数据库、对象存储、认证和领域能力。
- 保留现有 API 客户端和业务逻辑。
- 生产 Web 的壳层、导航、布局和页面组件按原型重做或大改。
- UI 验收以原型页面结构、主流程、状态和响应式行为为准。
- 功能测试继续运行；新增截图回归和人工逐页签收。
