# BYOK、租户隔离和删除必须有可执行门禁

V1 模型调用只允许 DeepSeek 官方和显式白名单 Provider。自定义 Base URL 必须 HTTPS，禁止私网、回环、链路本地地址和重定向。API Key 加密、界面掩码、永不进日志；正文、上下文包和 prompt 不写普通日志；追踪服务默认关闭或自托管。

所有租户故事表启用 RLS，以 `SET LOCAL app.user_id` 建立事务上下文；跨用户访问必须有自动化测试。账号注销前必须完成数据导出；作品永久删除前必须完成导出。账号和作品进入 30 天恢复期，期满后硬删除正文、版本、正史、上下文包、轨迹和孤儿数据；备份在 30 天内过期。

内容安全使用供应商能力 + 作者责任，不按关键词自动封禁；公开内容提供 AI 辅助生成标识、规则依据和申诉入口。

## Consequences

- 技术设计必须补租户表清单、RLS 策略、SSRF 测试矩阵、删除/恢复状态机和备份清理。
- UI 必须实现导出完成凭证和删除前确认。
- 发布前必须跑 RLS、SSRF、删除、恢复和内容审核回归。
