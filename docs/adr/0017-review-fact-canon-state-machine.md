# 章节批准、事实确认和正史提交是三段状态机

章节状态固定为：已规划、写作中、待审、要求修改、已批准、已锁定、已发布、已驳回。章节“批准”只表示正文通过审核并锁定章节，不等于事实进入正史。

事实提案状态固定为：已提案、已确认、已修改确认、已驳回、已替代。事实必须逐条或按明确规则批量确认，并记录来源章、来源句、操作者、时间和原因。只有“已批准/已锁定章节 + 已确认事实”或满足自动通过谓词时，Canon Curator 才能执行正史提交。

自动通过只允许：标准质量、锁定大纲、无高风险事件、无未解决 P0 冲突。人物死亡、金手指升级、已锁定事实修改、地图/势力根本变化、跨卷主线变更、分支合并永远需要人工确认。Canon Curator 是提交执行入口，不是自主决策者。

## Consequences

- 审核 API 必须拆成章节决策、事实决策、正史提交三个动作。
- 每次决策写入不可变审计记录，至少包含目标、动作、原因、操作者和时间。
- UI 必须把“批准章节”和“确认事实”分成两个可理解的动作。
