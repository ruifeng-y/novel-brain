# V1 只做选择性摘取，不做自动整分支合并

V1 不支持自动把整个平行版本合并回主线，只支持逐对象选择性摘取。可摘取对象包括：章节正文、事实、设定/实体、大纲、伏笔/剧情线；每个对象单独比较、单独决策、单独记录原因。

每个 merge item 包含：来源节点、目标分支、对象类型、对象 ID、差异、冲突状态、作者决策（接受/拒绝）、原因和风险等级。人物死亡、金手指升级、已锁定事实、地图/势力根本变化、跨卷主线变更必须二次确认。

摘取应用创建新的版本节点和正史提交节点，不覆盖旧版本；失败或撤销也创建新节点。禁止整分支静默覆盖。

## Consequences

- 需求中“V1 不做自动合并，只做选择性摘取”成为唯一口径。
- UI 必须按对象展示差异和冲突，不能只显示一段文本 diff。
- 合并/摘取必须留下逐项决策和审计记录。
