# 全本生产使用父任务、卷任务、章工作项和成本硬停

全本任务采用四层结构：父任务（全书）→ 卷任务 → 章工作项 → 步骤运行。每个工作项有状态、尝试次数、幂等键、检查点、费用和错误；失败章节默认不阻塞同卷其他章节，但卷边界必须停下来审核。

章节失败从失败步骤重试，不从头重写；正史提交串行；已完成章节保留。低风险章节只有在锁定大纲、标准质量、无高风险、无未解决 P0 时才允许自动通过；高风险和卷末必须人工确认。

成本按单章、单卷和每 1 万字统计。模型调用前预留预算，调用后结算；超限硬停并暂停任务，不静默降级或切换模型。

## Consequences

- `jobs` 必须增加父子关系、工作项类型和步骤尝试历史。
- UI 必须展示失败章节、检查点、分步成本和审核队列。
- 任务报告必须区分完成、失败、跳过、待审核和成本超限。
