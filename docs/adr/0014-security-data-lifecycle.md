# BYOK、日志、隔离与删除边界

V1 的模型调用只允许 DeepSeek 官方和显式加入白名单的 OpenAI 兼容服务。自定义 Base URL 必须使用 HTTPS，禁止私网、回环、链路本地地址和重定向，防止 SSRF。API Key 加密保存、界面掩码、永不进日志；正文、上下文包和 prompt 不写普通日志，只记录 ID、哈希、长度、状态和错误码。Langfuse 等追踪服务默认关闭或自托管，不向第三方发送正文和 Key。

所有租户故事表启用行级安全，并以 `app.user_id` 作为租户上下文；跨用户访问必须有自动化测试。注销进入 30 天恢复期，期满后硬删除作品、正文、版本、正史、上下文包和轨迹；备份在 30 天内过期，不可变历史随账号/作品一起删除，不保留孤儿数据。作者可先导出再删除，不设管理员查看作品和 Key 的权限。

## Consequences

- 技术设计必须补 SSRF、TLS、provider allowlist、RLS、删除 SLA 和备份清理契约。
- 需要跨租户隔离、删除、导出和追踪脱敏的自动化测试。
- “历史不可删除”只适用于作品存续期间；账号/作品删除后必须遵守删除承诺。
