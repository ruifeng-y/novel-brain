# 作者反馈默认不进入平台训练

平台记录结构化的作者反馈：接受、拒绝、改写、忽略问题、候选选择、修改原因和前后差异。这些反馈进入生成轨迹，用于质量评估、prompt 迭代和候选排序，不直接进入正史。

V1 不自动训练、不微调模型。Prompt、上下文策略、Agent 行为和模型参数的改动必须版本化，先跑固定基准集，再小范围灰度，不能直接全量上线。作者正文、设定、修改记录和反馈默认只用于该作者自己的作品和评测；未经明确授权，不进入平台训练集或跨用户共享。

## Consequences

- 平台进步速度受限于人工评测和 prompt 迭代，但作者数据边界清晰。
- 每次 prompt 或模型改动都要留下版本、基准结果和灰度记录。
- 后续若引入真实读者反馈或跨用户训练，必须重新做隐私和授权决策。
