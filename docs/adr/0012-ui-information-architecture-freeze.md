# V1 UI 信息架构冻结

V1 设定中心固定 7 个顶层栏目；题材固定仙侠、历史、都市三类；章节状态、作品状态和审核状态以需求文档为准。原型中的 10 个设定顶层栏目、悬疑/科幻题材和演示专用控件不进入 V1 生产 UI。

原型必须同步修正：移除高风险章节“忽略并继续”出口；复制作品默认不复制正文和版本；删除作品前必须有强制导出或明确确认；导入增加可选“设定提取”和导入报告；设定、题材、章节状态与需求一致。原型修正并签收后，才能作为 UI 验收基线。

## Consequences

- 生产 UI 不得同时照搬冲突的需求和原型；以本 ADR 和修正后的原型为准。
- 页面/动作/API 矩阵必须标出哪些控件仅用于演示，禁止进入生产。
- UI ticket 在原型修正签收前不得开始。
