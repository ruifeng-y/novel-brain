# 导入通过提案建立正史

作者可以从想法、部分设定、完整设定、已有正文或混合内容开始。导入不会直接把内容写进正史，而是走固定流水线：解析文件、章节切分、实体/事实/关系/时间线/伏笔候选抽取、冲突检测、作者确认、正史提交。

千万字正文按文件、卷、章分块后台处理，带检查点和断点恢复。正文说父母自杀、设定说仇杀这类冲突必须显式列出证据和影响范围，由作者裁决，不能自动选一个。导入生成独立作品和独立分支，不覆盖已有内容；导入文本视为不可信数据，不能执行文件内容或覆盖系统指令。

## Consequences

- 导入可能需要较长后台时间，并产生大量待确认候选。
- 高风险和低置信度候选必须逐条确认；高置信度低风险候选可以批量确认加抽检。
- 导入报告必须区分自动接受、待确认、冲突和无法解析。
