# 故事圣经、题材包、地图、力量体系和黄金三章是一等领域模型

故事圣经、题材包、自定义字段、地图、力量体系、金手指和黄金三章不能只藏在通用 `entities` 或 `works.settings` 的 JSONB 中。它们需要独立的结构、版本、锁定、校验和 API；通用实体可以引用它们，但不能替代它们。

故事圣经至少包含九卡、完成度、版本、锁定和修订记录。题材包包含 pack key、版本、必填字段、规则、UI schema 和迁移。自定义字段包含类型、适用对象、必填、选项、关系目标和启停。地图包含图层、节点、边、旅行时间、标记、势力控制区和人物位置。力量体系包含层级、路径、突破条件、代价、瓶颈、克制和资源。黄金三章包含候选、六维评审、作者决策、锁定和风格基线。

## Consequences

- 数据模型会增加专用表和约束，不能用一个通用 JSONB 字段糊过去。
- 每个领域对象都需要版本、锁定、迁移和题材差异测试。
- 原型页面必须有明确的数据落点，不允许只做展示壳。
