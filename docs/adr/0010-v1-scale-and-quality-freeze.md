# V1 规模与质量门槛冻结

V1 正式容量基线锁定为 1000 万字、3000–4000 章、30–40 卷，每卷 80–120 章，每章 2500–3500 字。需求、技术设计和原型里的 300 万字、1000 章、5 卷 150 章示例全部视为旧基线，必须同步更新。

“白金级”不作为无法验证的宣传承诺，而拆成可测量门槛：P0 事实丢失为 0；知识边界违规为 0；大纲贴合度不低于 90%；钩子与文笔评分不低于 4/5；目标读者追读率不低于 70%（有真实读者数据后启用）；连续性冲突不超过每 5 万字 1 个。质量目标是白金级，V1 验收按上述门槛执行。

## Consequences

- 容量、索引、备份、上下文预算、批处理、成本和压测全部按 1000 万字重新评估。
- 原型中的作品卡、卷章示例和统计数字必须改成与 1000 万字一致。
- 需求和技术文档中的旧规模、旧质量目标必须标记为已被本 ADR 覆盖。
