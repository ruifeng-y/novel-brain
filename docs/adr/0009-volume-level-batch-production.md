# 全本生产按卷推进并人工验收

千万字作品约 3000–4000 章、30–40 卷。全本生成采用父任务 + 卷子任务，按卷推进；草稿可以并行，正史提交必须串行；每章写检查点，失败从失败步骤恢复；卷末必须人工验收。

作者不需要逐章完整审阅。黄金三章和卷末关键章完整确认；低风险章节可以自动通过加抽检；异常章节进入审核队列。单章生成目标不超过 5 分钟；100 章卷可 overnight 批处理；每 1 万字成本单独统计并可配置上限。

## Consequences

- 生产系统必须支持父子任务、检查点、失败恢复、审核队列和成本控制。
- 自动通过必须建立在锁定大纲、标准质量和无高风险的前提上。
- 卷级验收是长线质量的闸门，不能等全本生成完再发现问题。
