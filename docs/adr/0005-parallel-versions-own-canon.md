# 平行版本拥有独立正史

作者可以从任意已提交版本点拉平行版本，支持按章、按卷和自定义区间。每个平行版本拥有独立正史、独立事件日志和独立快照，分支之间不共享可变状态，避免一边修改污染另一边。

合并回主线时，支持章节、事实、设定和伏笔状态分别摘取。合并前必须做冲突检测，列出会覆盖或冲突的主线内容，由作者逐项确认。涉及人物死亡、金手指升级、已锁定事实、地图/势力根本变化和跨卷主线变更时，必须额外确认。回滚生成新版本，不删除历史。

## Consequences

- 存储和版本图复杂度上升，但可以安全做 What-if、大修和回滚。
- 分支比较必须覆盖正文、事实、设定、大纲和伏笔状态，不能只比文本。
- 分支合并是高风险操作，必须保留审计记录和作者决策。
