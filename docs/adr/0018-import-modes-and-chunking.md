# 导入默认保留原文，设定提取是可选后台任务

V1 导入分两种模式：默认“文本导入”只解析文件、切分章节、整理标题和保留原文；可选“设定提取”由作者显式发起，才抽取人物、事实、关系、时间线和伏笔候选，并生成冲突报告。

千万字导入必须后台分块：父导入任务下挂文件/卷/章块子任务，逐块检查点、断点恢复、取消和部分失败。单文件大小、总大小和文件数量可配置，20 MB 只是原型演示限制，不是产品上限。导入文本视为不可信数据，只做数据解析，不执行内容、不覆盖系统指令。

导入生成独立作品和独立分支，不覆盖已有内容。冲突必须列出证据，由作者裁决；未确认候选不进入正史。

## Consequences

- 必须新增 Import 模块、导入任务表、候选/冲突/报告模型和断点恢复。
- UI 必须区分文本导入和设定提取，并展示导入报告。
- 必须补千万字夹具、损坏文件、重复章节、超大文件和提示注入测试。
