# 正史优先的故事状态

我们把世界事实、角色认知、叙事计划和文本分成四层。世界事实与角色认知构成正史；叙事计划是作者意图层；文本是正史的渲染结果。正文不是事实源，只有经过确认的事实和认知才能进入正史。

事实使用结构化记录，带主体、谓词、客体或值、类型、有效期、来源章、来源句和置信度。客观真相与角色认知分开存储，因此“父母是仇杀，但主角以为自杀”可以同时成立。正史提交采用不可变事件日志、快照和父提交，回滚产生新版本而不是删除历史。跨题材使用统一核心 Schema + 题材包自定义字段。

## Consequences

- 数据结构比“只存正文和提示词”复杂，但能支持长期一致性、知识边界和审计。
- 叙事计划中的伏笔、剧情线和人物弧不是世界事实，不能拿来当客观真相校验。
- 任何正史修改都必须留下提交、快照、原因和操作者。
