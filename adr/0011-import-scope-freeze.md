# V1 导入默认只保留原文

V1 导入分两种模式：默认“文本导入”只做解析、章节切分、标题整理和保留原文，不自动抽取人物、事实、关系、时间线或伏笔；可选“设定提取”是作者显式发起的后台任务，才执行候选抽取、冲突检测和作者确认。

ADR-0006 中的候选抽取流水线只属于可选的“设定提取”模式，不是默认导入。两种模式都生成独立作品和独立分支，不覆盖已有内容；导入文本视为不可信数据，不执行文件内容或覆盖系统指令。冲突必须列出证据，由作者裁决。

## Consequences

- 默认导入可以快速开始写作，不承诺自动建立完整正史。
- 设定提取会产生待确认候选和审核工作量，必须支持断点恢复和导入报告。
- 需求里“V1 导入不做全自动人物和设定抽取”继续成立；原型必须补充可选提取入口和报告。
